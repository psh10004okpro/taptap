# 콘텐츠 격차 분석: TapTap Titans vs 탭타이탄2 (2026-08 기준)

현재 빌드와 비교한다. 출처: TT2 공식 위키/패치노트/스토어 (조사일 2026-08-19).
최신 업데이트 확인: 2026-08-23 시작 Dungeon Quest 이벤트, Affliction Slot 전설 장비 세트, 젬스톤 개선.

## 총평

- 현재 빌드는 **TT2 "첫 1~3일 경험"의 축소판**이다. 코어 루프(탭→영웅→환생→유물)와
  광고 퍼널 구조는 갖췄지만, **빌드 다양성(스킬트리·유물 조합)과 소셜(클랜·레이드·토너먼트),
  시즌 러닝 콘텐츠가 전무**하다. TT2 리텐션의 본체는 후자다.
- TT2는 10년 라이브 팀의 산출물 — 전체 패리티는 목표로 삼지 않는다.
  **목표를 "TT2의 첫 30일 경험 패리티"로 정의**하는 것이 현실적이다.

## 30일 경험 패리티 로드맵 (우선순위)

### P1 — 성장 다양성 (다음 스프린트)
1. **영웅 8→24명** + 영웅별 패시브 스킬(마일스톤 레벨에서 해금: 크리+%, 골드+%, 보스뎀+% 등)
   → 지금의 "전부 같은 영웅" 문제 해소. config 데이터만으로 가능
2. **유물 6→20종** + 효과 다양화(오프라인+, 스킬 지속+, 환생 보상+ 등)
3. **장비 세트 효과** (같은 등급 3슬롯 = 세트 보너스) — 이미 있는 시스템 위에 소규모 추가

### P2 — 세션 러닝 콘텐츠
4. **토너먼트** (주말 24h, 신규 세이브 슬롯 경쟁 — 어비셜 방식이 서버 부담 적음)
5. **업적 시스템** (누적 목표 + 유물 보상)
6. 스킬 2종 추가(즉발기 Heavenly Strike형 + 마나 시스템 검토)

### P3 — 소셜/시즌 (서버 작업 큼)
7. 클랜(가입/채팅 없이 합산 랭킹부터) → 클랜 보스(비동기 협동)
8. 시즌제 (4주 단위 랭킹 리셋 + 보상) — 시즌 패스 BM의 전제
9. 펫/카드 — 성장축 추가는 P1-P2 소화 후

각 단계 완료 시 `npm run sim` 으로 페이싱 재검증 (docs/BALANCE.md 규칙).
