# 레이드 + 카드 설계 (서버 확보 후 구현)

> 상태: **설계 확정, 구현 보류.** 실시간에 준하는 서버 상태(공유 보스 HP,
> 주기 정산)가 필요해 Supabase 실프로젝트 + Edge Function 크론이 전제다.
> 스키마 초안: `supabase/migrations/draft/0004_raids_cards.sql`

## 목표
- 30일 이후 리텐션의 본체: 주간 협동 목표 + 카드 수집/성장 축
- TT2 모델(클랜 레이드 + 레이드 카드 + Dust)의 축소판으로 시작

## 루프
```
주간 레이드 개장(월 00시) ─→ 클랜원들이 공격권(일 1회)으로 카드 덱 전투
        │                        └ 공격 = 덱 DPS x 30초 (서버가 상한 검증)
        ▼
보스 처치 or 일요일 마감 ─→ 기여도 비례 보상: 카드 팩 + Dust
        │
        ▼
카드 강화(중복 카드 + Dust) ─→ 레이드 전용 데미지 상승 ─→ 다음 주 더 높은 티어
```
핵심 설계 결정: **카드는 레이드 안에서만 힘을 갖는다** — 본편 밸런스(sim)와
완전 분리된 별도 경제. 본편 인플레 없이 수집 축을 추가하는 TT2 방식.

## 카드 (초안 30종)
- 등급: 일반 12 / 희귀 10 / 영웅 6 / 전설 2
- 효과 축(레이드 한정): 부위 데미지%, 화상/감전 도트, 부위 파괴 보너스,
  공격권 +1(전설), 덱 시너지(같은 속성 3장 +%)
- 덱: 5장 장착. 강화: 동일 카드 N장 + Dust
- 획득: 레이드 보상 팩(확률 공시 필수 — EQUIP_BOX_RATES 와 같은 패턴으로
  config 단일 출처), Dust 상점(천장 역할)

## 레이드 보스
- 부위 3개(머리/몸통/꼬리) — 부위별 HP, 파괴 시 클랜 전체 버프
- 티어 1~10: 클랜의 직전 주 기록으로 자동 배정
- 보스 HP 공식은 `ClanBoss.bossHpFor` 확장 (클랜 인원 x 티어 스케일)

## 서버 검증 (submit-score 와 동일 철학)
- 공격 제출: 덱 구성 + 클라 계산 데미지 → 서버가 카드 원장 기준 상한 재계산,
  초과분 클램프. 공격권/쿨다운은 서버가 관리 (클라 신뢰 금지)
- 카드 지급은 서버 원장(`card_ledger`)만 — 클라는 조회 캐시

## 구현 착수 조건 체크리스트
- [ ] Supabase 실프로젝트 (익명 인증 + 크론 확장 활성화)
- [ ] 클랜 온라인 전환 (clan-ops 배포 + 가입 UI 원격 모드)
- [ ] 주간 정산 크론 (pg_cron 또는 Scheduled Edge Function)
- [x] 카드 30종 데이터 시트 + 레이드 전용 시뮬 (`src/core/raid.ts`, `npm run sim:raid`)

## 경제 검증 결과 (2026-08, `npm run sim:raid`)

구현 전에 수치가 성립하는지 먼저 봤다. **초안 수치는 세 군데가 깨져 있었다.**

| 문제 | 증상 | 수정 |
|---|---|---|
| 티어 스케일 2.4배 | 티어 2 에서 26주 내내 정체 — 덱은 같은 기간 1.6배밖에 못 자란다 | 1.28배 |
| 중복 처리 규칙 | Dust 가 26주 내내 0. 중복이 30종에 흩어져 레벨도 Dust 도 안 오름 | 덱 밖 카드의 중복은 즉시 분해 |
| 전설 천장 30,000 | 누적 수입이 800 남짓이라 평생 도달 불가 — 확률에만 갇히는 설계 | 900 + 주간 직접 Dust 보상 |

주간 보상에 **직접 Dust** 가 빠져 있었던 것도 시뮬에서 드러났다 (문서에는
"카드 팩 + Dust" 라고 적혀 있는데 수치가 없었다).

조정 후 (시드 3개):

```
덱 5장 완성:   2주 / 2주 / 2주       (기준: 4주 이내)
첫 전설:       10주 / 12주 / 11주    (천장이 실질 획득 경로로 작동)
26주차 티어:   5 / 7 / 8  (상한 10)  (실패 주가 중간에 섞임)
```

판단 기준: 덱 5장이 4주 안에 차야 첫 달 안에 "덱을 짜는 재미"가 시작되고,
전설은 확률만으로는 수십 주가 정상이되 천장이 실제로 닿아야 하며,
티어가 매주 오르기만 하면 보스가 장식이 된다.

`src/core/raid.ts` 는 **어떤 씬도 import 하지 않는다** — 트리셰이킹으로 번들에서
빠지는 것을 확인했다. 서버가 준비되기 전까지는 데이터와 공식만 존재한다
(카드 지급 원장은 서버에만 둔다는 결정은 그대로다).
