# 밸런스 시뮬레이터

렌더링 없이 `src/config.ts` 곡선만으로 진행을 재현한다. **곡선을 바꾸면 반드시 시뮬을 다시 돌려 벽 위치를 확인할 것.**

```bash
npm run sim          # 3일 시뮬, 프로필 3종 상세 리포트 (sim/out/latest.json 덤프)
npm run sim -- 7     # 7일 시뮬
npm run sim:tune     # 한 줄 요약 (파라미터 스윕용)
```

## 플레이어 모델
- 탐욕적 준최적: 매 결정 시점에 ΔDPS/비용 최대 업그레이드 반복 구매
- 스킬은 평균 가동률(지속/쿨다운)로 상시 배율 환산
- 정체(4분) + 의미 있는 유물 보상이면 환생, 유물은 ROI 순 소비
- 프로필: 액티브(4탭/s), 캐주얼(1탭/s), 저관여(0.25탭/s·스킬 미사용)

## 핵심 발견 (2026-08)
**골드가 몬스터 HP 에 비례(HP×0.2)하던 초기 설계는 벽이 생기지 않는다** —
수입이 난이도를 항상 따라잡아 37분 만에 스테이지 400 논스톱, 환생 무의미.
→ 골드를 독립 곡선으로 분리하고 `GOLD_GROWTH < HP_GROWTH` 격차가 벽을 만들게 함.

## 채택 페이싱 (1.42, 액티브 기준)
- 첫 세션: 스테이지 60-80, 첫 환생 50분 (+46 유물) — D1 훅
- 환생 주기: 50m → 1.7h → 5.5h → 14h → 32h (점증 = 자연스러운 세션화)
- 벽: 소프트(5분+) 스테이지 ~105부터 연쇄, 3일 max ≈ 148
- 저관여도 1시간 내 첫 환생 경험
